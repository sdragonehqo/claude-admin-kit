description: Pages and charts built for the user open in light mode by default
metadata:
  type: feedback
---

Pages and charts built for the user open in light mode by default; use dark only if the user asks.

**Why:** Light output prints, screenshots and pastes into documents cleanly, and it is what most readers expect from a business page.

**How to apply:** When building a page, chart or diagram, use a light theme unless the user asks for dark. If a diagram tool offers a theme toggle, leave the reader's choice alone once they make it.
